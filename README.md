# SQLRunner
## Objetivo

Esse projeto tem o objetivo de criar um programa que execute A linguagem SQL(Structured Query Languege) e através disso entender como funciona os mecanismos da execução do sql por baixo dos panos, e aplicar conhecimentos de algoritmos de busca , ordenação , arvores b+ e orientação a objetos.

## Desenvolvimento

Tecnologias usadas
- Python 
- Git e GitHub
- Docker

Relatórios do projeto
Os relatórios do projeto podem ser buscados na pasta reports e cada arquivos estaá na estrutura .txt informando o dia que foi feito.
