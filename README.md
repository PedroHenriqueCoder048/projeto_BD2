# SQLRunner
## Objetivo

Esse projeto tem o objetivo de criar um programa que execute A linguagem SQL(Structured Query Languege) e através disso entender como funciona os mecanismos da execução do sql por baixo dos panos, e aplicar conhecimentos de algoritmos de busca , ordenação e arvores b+

## Desenvolvimento

Tecnologias usadas
- Python 
- Git e GitHub
- Docker
